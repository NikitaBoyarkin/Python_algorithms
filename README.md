# Python Algorithms

A small collection of classic algorithms implemented from scratch in Python,
written as practice. This is study code, not a library — there is no packaging,
no test suite and no CI.

## What's inside

| File | Algorithm |
|---|---|
| `bubble sort.py` | Bubble sort |
| `insertion sort.py` | Insertion sort |
| `selection sort.py` | Selection sort |
| `quick sort.py` | Quicksort |
| `bogo sort.py` | Bogosort (worst-case illustration) |
| `binary search.py` | Binary search |
| `Graham scan.py` | Graham scan (convex hull) |
| `single-layer perceptron.py` | Single-layer perceptron |

## Requirements

Python 3 only — no third-party dependencies.

## How to run

```bash
python "bubble sort.py"
python "binary search.py"
```

Most files run a small demo or print their output when executed directly.
